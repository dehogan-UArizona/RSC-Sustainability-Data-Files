The provided Gaussian Job Files (GJFs) and PDFs support the molecular modeling work described in the publication titled “Conditional Stability Constants for Six Synthetically-Derived, Bio-Inspired Glycolipids”. The JGF files served as input files, containing the initial Cartesian coordinates of the simulated molecules. Complexation of lead (II) ions (Pb2+) with the monorhamnolipids was investigated by employing ab initio simulations, which were performed using the Gaussian (version 6.1.1) simulation package. Molecular modeling was conducted to explore the most stable metal-oxygen coordination number for monorhamnolipid:Pb2+ complexes and whether increasing the tail length of the lipid would impact the binding of Pb2+ ions, as described in the manuscript.
